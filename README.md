# Neuron Lab / 神经网络实验室

面向新手的中英双语交互式神经网络网站。原生 HTML、CSS、JavaScript，无需安装依赖，无外部字体或服务。

## 运行

直接双击 `index.html`，即可在浏览器中使用全部功能，无需启动服务器，也无需网络连接。

如果需要通过本地网址访问，也可以运行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。此网址仅在服务器运行时可用；关闭服务器后，请直接打开 `index.html`。也可以用任意静态文件服务器托管本目录。

## 五个实验

1. 线性回归：学习时间与成绩，手动调整 θ₀ / θ₁。
2. 线性梯度下降：同一数据，查看梯度、单步或自动训练。
3. 非线性回归：简单对称的 U 形滑道截面（位置与高度），调整 1–3 个隐藏层、每层 1–10 个神经元及全部权重和偏置。
4. 非线性梯度下降：保留咖啡店客流数据，实际反向传播和梯度下降，可调整学习率。
5. 分类：根据水果重量预测品种，sigmoid 概率、交叉熵及准确率。

所有关卡可随时切换。下方按层逐个列出神经元运算，例如 `h₁ = ReLU(w₁ × X₁ + b₁)`；下一层明确引用上一层的隐藏输出，输出层完整展开全部加权项。每个权重和偏置都有唯一编号，点击表达式中的 `w` 或 `b` 可定位对应滑块。点击网络中的神经元会突出对应计算行，调整滑块实时更新预测与损失。

界面采用暖白底、墨蓝权重和暗红偏置，loss 也使用暗红；正负权重通过实线/虚线区分。右上角「复位 / Reset」会暂停训练，恢复当前关卡的默认网络结构、全部参数、学习率、所选样本和正在观察的神经元，并清空训练记录；保留当前语言。改变结构也会重新开始训练记录。语言偏好保存在本地；训练数据不上传。

教学数据由固定函数生成，并非真实调查或科学结论。回归以 0–1 缩放值计算 MSE；分类使用二元交叉熵。隐藏层使用 ReLU，回归输出层为线性，分类输出层为 sigmoid。训练使用全批量解析梯度，必要时缩小步长来避免损失增加，界面会显示实际步长。

## 验证

```sh
npm test
```

检查反向传播与有限差分是否一致，以及三个可训练关卡能否达到学习目标。
